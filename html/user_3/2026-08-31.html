  • Abstract: Softmax attention stores key and value vectors for every preceding token, causing inference memory to grow with sequence length.   • 摘要：手语生成 (SLP) 旨在从口语中生成连续的手语动作，通常是通过注释到姿势的生成。先前的工作主要遵循两种范式。生成模型根据学习到的先验知识或噪声来合成运动，而不参考观察到的手语实例，使得罕见的手部配置和特定于手语者的发音难以保留。基于检索的方法重用真实的、清晰表达的运动片段，但连接来自不同手语者和共同发音上下文的片段可能会在整个序列中引入节奏和风格不一致，而不仅仅是在片段边界处。这些限制提出了一种补充解决方案：使用检索来提供真实的表达，并使用学习的细化来强加单独检索所缺乏的全局连贯性。因此，我们提出检索和细化，这是一种从真实检索的运动开始并将其细化为全局一致的签名序列而不是从头开始生成运动的范例。我们的框架 SignRR 从真实符号片段字典中初始化运动，并使用部分感知残差 VQ-VAE 细化完整序列，其中残差量化保留了精细的手部清晰度，并且在潜在空间中处理时间长度差异。 PHOENIX14T 和 CSL-Daily 上的实验表明，SignRR 实现了最先进的反向翻译性能，同时保持了有竞争力的姿势质量。
